# OLED chassis + TrainHeroic session

Status: **shipping direction.** Home stays OLED Whoop-adjacent. Training + logger borrow TrainHeroic grammar only. Not a 1:1 TrainHeroic reskin. Not Track Dawn. Not Morph.

## How the mix works

OLED is the **room**. TrainHeroic is the **session instrument**.

| Surface | Language |
|---------|----------|
| Home, Me, nav, WHOOP dials | OLED: true black, `#121212` sheets, Space Grotesk body, Barlow Condensed for the date, quiet outline CTAs, recovery/strain/sleep arcs unchanged |
| Training board + logger + rest | TH: 8px gray letter tiles, orange **rx only**, white **Start Session / Start work**, giant white work clock, thin white rest ring, done-green checks |

Orange never fills a screen. WHOOP lime/blue never become app chrome. Mint Engine tiles stay dead.

## Three ways we could have mixed it

1. **Split rooms (this one).** OLED Home. TH only after you open Training or a session. Clearest: dials stay WHOOP, the board looks like a logger.
2. **OLED everywhere, three TH souvenirs.** Tiles + orange rx + giant clock, but Home outline CTAs even on Start work. Quieter; Start work reads less like TrainHeroic.
3. **Full TH paint.** Barlow everywhere, white bricks on Home. That is what we just did. It erases OLED.

## Do not

- Morph wordmark
- Track Dawn mint / work-red / rest-blue
- Copper Strength
- White Start brick on Home Create session (that stay OLED outline)
