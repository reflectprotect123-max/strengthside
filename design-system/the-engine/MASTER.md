# Design System Master — The Engine (athlete)

> OLED chassis + TrainHeroic session grammar. 24 Sep 2026.
> Full TrainHeroic reskin and Track Dawn mint/red/blue are **rejected**.
> Not Morph wordmark. Not copper Strength.

## Subject

Indoor Engine session. Home is readiness. Training/logger is the board.

## Signature

Home: three WHOOP dials on true black. Session: gray letter + orange rx + one white Start bar + giant white clock.

## Do not

- Morph logo or the word Morph in the athlete UI
- Full-bleed mint / work-red / rest-blue
- Copper Strength chrome
- WHOOP lime as logger chrome
- Barlow as the Home body face
