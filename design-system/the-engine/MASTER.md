# Design System Master — The Engine (athlete)

> Source of truth for `apps/athlete` logger/home. Persisted 24 Sep 2026.
> Tool-default cinema orange CTA and Track Dawn mint/red/blue are **rejected**.
> Brief: TrainHeroic logger structure. Not Morph wordmark. Not copper Strength.

## Subject

Indoor Engine session (Echo / row intervals). Job: see the letter, start the session, run work/rest.

## Tokens

| Role | Token | Value | Rule |
|------|-------|-------|------|
| Void | `--oled-bg` | `#000000` | True black, TrainHeroic |
| Surface | `--oled-surface` | `#121212` | Sheets, pad |
| Tile | `--tile` | `#3A3A3C` | Letter squares |
| Ink | `--oled-text` | `#FFFFFF` | Titles, clock |
| Mute | `--oled-muted` | `#8E8E93` | Kickers |
| Rx | `--rx` | `#FF7A1A` | Prescription numbers only |
| CTA | `--cta` | `#FFFFFF` | Start Session / Log |
| CTA ink | `--cta-ink` | `#000000` | On the white bar |
| Done | `--done` | `#34C759` | Set checks only |
| Type display | `--font-display` | Barlow Condensed | Letters, titles, clock, CTA |
| Type body | `--font-body` | Barlow | Notes, tables |
| Tap | `--tap` | `44px` | All primaries |

WHOOP recovery/strain/sleep colours stay on Home dials only.

## Signature

One white **Start Session** bar. Giant white work clock. Rest is a thin white ring. Orange never fills a screen.

## Do not

- Morph logo or the word Morph in the athlete UI
- Full-bleed mint / work-red / rest-blue (Track Dawn)
- Copper Strength chrome
- WHOOP lime as app chrome
