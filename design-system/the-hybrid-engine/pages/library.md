# Library — page overrides

Primary job: **reuse templates** (edit / duplicate / save / schedule). Building new is secondary.

## Hierarchy on each template card

1. **Name + short meta** (expand for overview)
2. **Edit | Duplicate** — peer secondary actions, always visible (≥44px, ≥8px gap)
3. **Schedule** — single full-width primary CTA
4. **Delete / Hide** — low-emphasis danger, never same weight as Schedule

## Copy

- Hero: “Templates” — not “Workouts”
- Lead: edit, duplicate, save, then schedule when needed
- CTA: “New strength template” / “New conditioning template”

## Do not

- Hide Edit/Duplicate behind expand
- Four equal buttons in a flat 2×2 with no primary
- Require expand to discover everyday actions
