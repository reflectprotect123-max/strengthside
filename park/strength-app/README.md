# Parked strength app

This is the Hybrid Strength athlete app: the session builder, the logger, and the strength brain. It is parked. It is not the app that opens.

The app that opens is the Engine, at `apps/athlete/index.html`, which goes straight to `apps/athlete/engine/index.html`.

Nothing in this folder was deleted. Open `index.html` from this folder to run the strength app on its own. Bike, Row, Run, Ski, and Jump Rope are not seeded onto a new session.

Do not ship this tree on the Engine channel.
