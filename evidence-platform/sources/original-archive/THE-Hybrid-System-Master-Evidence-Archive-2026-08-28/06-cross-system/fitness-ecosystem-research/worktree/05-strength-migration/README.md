# Phase 05 — Strength migration

Branch: `phase/05-strength-migration`

## Goal

Preserve the current Strength user experience and historical data while removing Conditioning ownership from the product.

## Tasks

- identify the canonical existing install identity;
- keep old-reader support during the migration window;
- project strength history and results without deleting source records;
- test upgrades, reinstall, deep links, and account changes;
- add user-facing explanation of the second app;
- verify no Conditioning data is silently lost.

## Exit criteria

Migration rehearsal passes with checksums, old/new clients, offline races, deletion, rollback, and support instructions.
