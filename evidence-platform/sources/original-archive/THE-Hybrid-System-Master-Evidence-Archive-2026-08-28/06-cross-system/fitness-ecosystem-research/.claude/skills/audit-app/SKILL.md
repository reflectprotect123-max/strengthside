# Audit the existing app

Use for the first read-only phase.

1. Locate the canonical checkout and record the path.
2. Inventory package managers, workspaces, apps, build scripts, CI, deploys, native integrations, and tests.
3. Trace auth, local storage, Supabase reads/writes, merge/sanitize rules, and deletion.
4. Trace Strength, Conditioning, WHOOP, pain, illness, readiness, calendar, history, and balance call sites.
5. Record measured facts with `verified`, `provided`, `inferred`, or `unknown`.
6. Do not change source.
7. Write `BASELINE_AUDIT.md` and exact command results.

Stop if the source contradicts a safety or ownership boundary in `CLAUDE.md`.
