# THE Hybrid System — Master Evidence Archive

**Archive date:** 28 August 2026  
**Purpose:** one consolidated handoff containing the existing research, evidence, system designs, plans, schemas, validation material and visual architecture assets for THE Hybrid System.

## What is included

This archive brings together the work already produced for the five systems:

1. Strength
2. Conditioning
3. Nutrition
4. Recovery
5. Coordinator

Those five systems feed the **Multi-model adaptive control system**, which is the non-LLM learning and decision layer.

## Folder guide

- `00-governance/` — master plan, evidence-platform README, traceability design, schemas, SOPs and the Decision Hub research briefing.
- `01-strength/` — MacroFactor/RP strength research, formula and claim registries, test vectors, audits, exercise library, strength-side research, plans and specifications.
- `02-conditioning/` — conditioning evidence handoff, progression research, modality rules, Concept2 and ECHO connectivity research, contracts and source manifests.
- `03-nutrition/` — MacroFactor research, PubMed validation, formula registry, claim matrix, test vectors, implementation checklist and MacroTrack planning material.
- `04-recovery/` — recovery, readiness, progression/regression, pain-aware training, weekly-review and evidence-audit research.
- `05-coordinator/` — Coach Brain model specification, coaching-platform research and onboarding/check-in research.
- `06-cross-system/` — integrated Hybrid evidence dossier, fitness-ecosystem research, cross-system specifications and build planning material.
- `07-repo-research/` — reserved for future repository-level evidence imports; no application source or dependency trees are included here.
- `08-visual-assets/` — decision-hub, solar-system, galaxy and architecture visual prototypes.
- `09-original-archives/` — original ZIPs retained unchanged for exact provenance and comparison.

## Important status note

This is a consolidated archive of the existing work. It is not the completed 5–15 million-line evidence corpus, and it does not claim that every proprietary MacroFactor or RP coefficient has been recovered. The archive preserves the distinction between documented evidence, research interpretation, product policy, executable rules, model parameters and unresolved gaps.

## Authority rule

The archive is a research and design handoff. Runtime athlete decisions must come from versioned, validated non-LLM models and rules. Any LLM-assisted extraction or classification remains untrusted until it is checked against the source, schema, provenance requirements and review gates.
