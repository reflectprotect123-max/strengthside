# Play with the app (interactive)

## Open this (not htmlpreview)

https://raw.githack.com/reflectprotect123-max/strengthside/cursor/mobile-home-screen-2ff0/apps/mobile/THE-Hybrid-App.html

Click **Open the page** if asked. Tap **CONDITIONING**, then **Start** to connect a Bluetooth heart-rate strap (Polar / Wahoo / most chest straps). The half-gauge shows live bpm; Complete stores the average. Chrome on Android or desktop — Safari on iPhone cannot use Web Bluetooth.

**Update** in the top right jumps to this same live file so you are not stuck on an old preview.
