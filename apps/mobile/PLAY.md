# Play with the app

This HTML file **is** the athlete app.

https://raw.githack.com/reflectprotect123-max/strengthside/cursor/mobile-home-screen-2ff0/apps/mobile/THE-Hybrid-App.html

Click **Open the page** if asked. Tap **CONDITIONING**. **Connect strap** pairs a Bluetooth heart-rate strap (Polar / Wahoo / most chest straps). **Start** is only the clock. The half-gauge is live bpm; Avg HR below is the session number. Chrome on Android or desktop — Safari on iPhone cannot use Web Bluetooth.

**Update** in the top right jumps to this same live file so you are not stuck on an old preview.
