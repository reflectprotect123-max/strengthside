# Capacitor dogfood shell — THE Hybrid athlete app

Wraps `apps/mobile/preview-site` (synced from `prototype/hybrid-app`) in an Android WebView for device dogfood. Not a Play Store release track.

## Prerequisites

- Node 20+ / pnpm
- Android Studio or command-line SDK (API 34+), `ANDROID_HOME` set
- JDK 17+ (Capacitor 8)

## Sync web → native

From repo root:

```bash
bash apps/mobile/sync-hybrid-html.sh
cd apps/mobile/capacitor && pnpm install && pnpm run sync
```

## Build dogfood APK

```bash
bash apps/mobile/capacitor/scripts/build-dogfood-apk.sh
```

APK lands under `apps/mobile/capacitor/android/app/build/outputs/apk/debug/` (and is copied to `/opt/cursor/artifacts/` when that path exists).

## Native modules used

| Plugin | Why |
| --- | --- |
| `@capacitor-community/keep-awake` | Screen on during Engine / Strength sessions |
| `@capacitor/camera` | Nutrition label photo for OCR |
| `@capacitor/app` | Background → release wake lock |

OCR runs **on-device** in the WebView (Tesseract) after the camera capture; parse uses `HybridNutrition.Core.parseLabelText` / `parseLabelLines`. ML Kit can replace the recognizer later without changing Nutrition UI.

## Do not

- Point `webDir` at Expo or deleted athlete shells
- Commit `android/app/src/main/assets/public/` (regenerated by `cap sync`)
