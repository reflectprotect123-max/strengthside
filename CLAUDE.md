# The Engine

This tree is the athlete Engine app and the adaptive brain.

- App: `apps/athlete/`
- Adaptive math: `packages/adaptive/`
- Daily packet: `packages/brain/`
- Android shell: `apps/mobile/capacitor/`

`pnpm run check:athlete-app` is the athlete gate. `pnpm run verify` is typecheck, package tests, migrations, the brain bundles, and the athlete checks.

Do not add a coach app, a strength house, or an evidence archive back into this tree.
